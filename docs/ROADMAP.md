# Düzenleme ve geliştirme sırası

## 1. Anlaşılabilirlik ve depo temizliği

- [x] Proje amacı, analiz zinciri ve dosya görevlerini açıklamak.
- [x] Kalça yer değiştirmesi, uçuş yüksekliği ve GCT'yi ayrı tanımlamak.
- [x] Önceki uzak README'yi arşivlemek; doğrulanmamış sayıları güncel iddia olarak sunmamak.
- [x] Ignore desenlerini düzeltmek; yerel video ve model kopyalarını korumak.
- [x] Boş yanlışlık dosyalarını, önbellekleri, ağırlıkları ve ham videoları Git takibinden çıkarmak.

## 2. Kurulum ve deney yönetimi

- [ ] Temiz ortamda kurulabilen bağımlılık dosyası hazırlamak ve doğrulamak.
- [ ] Gömülü üçüncü taraf repoları submodule veya kurulum betiğiyle yönetmek.
- [ ] Model kaynakları, revizyonlar ve dosya özetlerini kaydetmek.
- [ ] Sabit video yollarını ve kalibrasyon değerlerini yapılandırmaya taşımak.
- [ ] Yerel arayüz geliştirmelerini ayrı kapsamda incelemek.
- [ ] Her koşuya deney kimliği, parametreler ve bağımlılık sürümleri eklemek.

## 3. Ölçüm doğrulaması

- [ ] Başlangıç, kalkış, tepe, iniş ve zemin tanımlarını belgelemek.
- [ ] Drop Jump için kutu/bekleme/reaktif temas ayrımını doğrulamak.
- [ ] Kalibrasyon aracının eski parametre mesajını ve sabit uzunluk varsayımını düzeltmek.
- [ ] Aynı videoda, aynı referansla, aynı kalibrasyonla modelleri karşılaştırmak.
- [ ] Yinelenen model etiketlerini ve arşiv tablosunun veri kaynağını çözmek.
- [ ] Boş veri, poz kaybı ve bilinen hareketler için anlamlı testler eklemek.

## 4. Sunum

- [ ] Paylaşılabilir örnek veri ve beklenen çıktı eklemek.
- [ ] Ölçülmüş sonuçları deney kayıtlarından üretilen bir tabloyla sunmak.
- [ ] GitHub ile yerel değişiklikleri karşılaştırıp incelenebilir commit hazırlamak.

Git takibinden çıkarma geçmiş commitlerdeki büyük dosyaları silmez.
Geçmişi yeniden yazma bu adımın kapsamına dahil edilmemiştir.
